## 👨‍💻 About / Sobre

Interactive bilingual (**PT / EN**) portfolio website of **Tiago Filipe Fernandes dos Santos Alves Custódio** — **Python (Django) Developer, Cisco-Certified Cybersecurity Specialist, and Systems & Network Engineer**.

### ✨ Key Features
- **60fps Multi-Layer Parallax Engine**: Custom scroll and 3D mouse-depth parallax with interactive constellation canvas.
- **Bilingual Architecture (`PT` / `EN`)**: Instant client-side language switching without page reloads (`js/data.js` + `js/main.js`) and dedicated `/en.html` entry point.
- **Tech Arsenal Bento Grid**: Interactive spotlight hover cards and animated competency bars across Software Engineering, Cybersecurity, AI, and Infrastructure.
- **Verified Credentials Vault**: 3D tilt cards showcasing 12 official certifications (**Cisco Networking Academy**, **OpenEDG Python Institute**, **Tokio School**) with an embedded PDF Lightbox Viewer.
- **Interactive Cyber-Terminal**: Built-in developer/recruiter console (`whoami`, `skills`, `certs`, `experience`, `contact`, `cv`).
- **Live GitHub Sync**: Automatically fetches and displays public repositories from `github.com/tiagofcustodio`.
